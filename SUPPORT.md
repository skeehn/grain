# Support Policy

Use GitHub issues for reproducible bugs and discussions for usage questions.
Security reports follow `SECURITY.md`. Include Grain version, OS, terminal, Bun
version, provider/executor, a redacted journal excerpt, and minimal reproduction.

Before 1.0, support is best-effort for the latest release on macOS and Linux.
Windows, experimental workflows, live provider matrices, and third-party CLIs
outside the compatibility matrix are not release-qualified.
